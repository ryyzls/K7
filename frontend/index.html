206 Rumah Sakit Terdata

Data klasifikasi Kelas A, B, C, D sesuai regulasi Permenkes No. 3 Tahun 2020 di seluruh 33 kabupaten/kota Sumatera Utara.

Linked Open Data (DBpedia)

Ontologi W3C terhubung dengan owl:sameAs ke DBpedia global untuk data geospasial dan profil wilayah yang kaya.

Navigasi Rute Cepat OSRM

Perhitungan rute berkendara dan jarak tempuh otomatis dari lokasi GPS pengguna secara real-time via OpenStreetMap.

Reservasi Kamar Simulasi

Simulasi pemesanan kamar rawat inap (VIP, Kelas 1-3, ICU) terhubung ke basis data relasional PostgreSQL untuk riset MSBD.
